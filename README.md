Built with **Next.js · React · Convex DB · Clerk Auth · Arcjet · AI SDKs**

### 📈 [Stock Price Prediction (Stacked LSTM)](https://github.com/namratapagariya/stock-price-prediction)
> Deep learning model to forecast AAPL stock prices using sequential time-series data.

Built with **Python · Keras · LSTM · Google Colab · Matplotlib**

- Used 60-day sliding window sequences as input to capture temporal patterns
- Applied MinMaxScaler normalization to stabilize gradient flow
- Visualized actual vs. predicted trends to evaluate model accuracy
